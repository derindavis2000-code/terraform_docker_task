-Terraform\_Docker\_TASK



-Objective

&nbsp;Provision a local Docker container using Terraform.



-Tools Used

\- Docker Desktop

\- Terraform

\- WSL2



-Steps Performed

1\. Installed Docker Desktop

2\. Installed Terraform

3\. Created main.tf

4\. Ran terraform init

5\. Ran terraform plan

6\. Ran terraform apply

7\. Verified nginx at http://localhost:8080

8\. Checked terraform state

9\. Ran terraform destroy



-Result

Nginx container successfully deployed and destroyed using Terraform.
